- Duplicate payment-reference protection is normalized and database-enforced.

- Resend API access exists only in Supabase Edge Function code via environment secrets.

- Product/settings/rates/credit/user-status actions are admin-only.
- Admin UI includes all supported order states: New Order, Awaiting Payment, Processing, Completed, Cancelled and Rejected.
- Cancelled/Rejected/fulfilled orders cannot be dragged as active Kanban work.
- Admin and guest-tracking utility pages are marked noindex,nofollow.
- No old localStorage order/catalog database or IndexedDB proof store remains as the financial source of truth.
- No demo admin password remains in the frontend.
